# 完成的定义

**不满足以下任一条，不算完成。**

## 自动判定

```bash
# 1. 在 Illustrator 里对产物运行 tools/_audit_output.jsx（只读，跑完不要保存）
# 2. 然后：
python3 tools/verify_poster.py killer90mins_2026XXXX/<...>_L4.txt briefs/<date>.json
```

必须全部 PASS：

| 项 | 判定 | 容差来源 |
|---|---|---|
| **R0** 黑板上沿 → 名牌墨迹顶，垂线 | **逐格** ± 1.0 mm | 见 `config/slots.json`；两份认可文件的均值 |
| **R2** 名牌墨迹下边 → 人像轮廓，最小垂线净距 | 12.0 ± 1.0 mm | 认可稿实测 11.45–12.56 |
| **R3** 头部最宽处到黑板左右两侧，\|左−右\| | ≤ 5.0 mm | 认可稿最差 4.21 |
| **R1** 名牌墨迹中心 vs 黑板中心 | ≤ 1.5 mm | 认可稿最差 1.25 |
| **COV** 人像底部超出黑板最低角 | ≥ 1.0 mm | 无透明缝 |
| 第五格模式 | 与 brief 一致 | — |
| 日期四个文本 | 与 brief 逐字一致 | — |
| HOST 徽章 | 落在 brief 指定的格 | — |

容差取「不严于设计师手工水平」。**改容差前，先确认认可稿仍能通过。**

## 验收脚本自己的验收

```bash
python3 tools/verify_poster.py /tmp/ref_v3_L4.txt /tmp/ref_v3_brief.json
```

拿 `killer90mins_20260819/killer90mins_v3.ai`（设计师认可）跑，**R1 / R2 / R3 / COV 必须五格全 PASS**。
通不过 = 验收脚本有 bug 或容差定错，**先修它，不要改产物**。

**R0 是例外**：v3 在 R0 上 4/5 不达标，因为逐格 R0 是**在它之后**才从两份认可文件反推出来的，
v3 本身早于该规则。R0 的对标基准是 `config/slots.json` 里的逐格值，不是 v3。
这个例外必须显式知道——否则要么误以为验收脚本坏了，要么为了让 v3 通过而放宽 R0 直到它失效。

## 人眼确认（不可省）

1. **L2 核对图** —— 品红线压在发顶、绿框在太阳穴或眼睛高度、黄线穿过脸中心
2. **成品与认可稿并排** —— 四个人的头大小是否一致；某人明显偏大偏小，改 brief 里那一个 `target_head_width_mm`
3. **第五格** —— 剪影与「SECRET GUEST」是否正确显示
   —— 该格名牌**未旋转**（与上沿差 8.07°）、两行、字号 45.61，脚本不动它，属模板既有状态
4. **中文名** —— 白字、无框、位置合理

## 幂等性

同一份 s1 连跑两次 stage2，**导出的 PNG 必须逐像素相同**。

**以产物的字节为准，不以 L4 报告为准。** 已实测：PNG 0/15,431,472 像素差异，
但 L4 报告有 1 行差 0.0004pt——`createOutline()` 量中文字体墨迹时有微米级不确定性。
测量本身也是一次计算，会引入自己的噪声；产物的字节才是事实。

前提：stage2 里**不能有任何相对操作**（`translate` / `resize`）。全部用绝对赋值
（`.left=` `.top=` `.width=` `.height=`），否则跑两次会叠加。

## 失败时

> 回去改 `config/slots.json` 或 `actors/<id>.json` 里的**一个数字**，然后**整体重跑**。
> 不写补丁脚本，不在上一版输出上继续改。
