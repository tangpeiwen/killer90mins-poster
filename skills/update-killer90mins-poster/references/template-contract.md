## 图层结构

```
日期/时间/主持人标签        ← 图层名字面含斜杠
  MONTH / DAY / WEEKDAY / EVENT TIME   点文字，各自命名
  HOST BADGE                           组；靠 x 落在哪一格判断归属
STATIC                                 背景 / KILLER / logo / 二维码 / 底部信息，锁定不动
ACTOR_01 .. ACTOR_04
  NAME                                 点文字
  PHOTO（ACTOR_03 是 PHTOTO，拼写错误）
    剪切路径 + PlacedItem
ACTOR_05
  SECRET_GUEST_MODE   组，hidden 切换
  黑色背板             组
  PHOTO_MODE          子图层，visible 切换
    NAME + PHOTO
```

## 字体

| 用途 | 字体 | 字号 |
|---|---|---|
| 拉丁名 / 日期 | `LaMachineCompany` | 54.25（长名可降，chin wang 用过 49.19） |
| 神秘嘉宾 | `LaMachineCompany` | 45.61，内容两行（`secret\rguest`） |
| 中文名 | `Huiwen-MinchoGBK-Regular` | 54.25，**白色填充，无白框** |

**白色印章板是 `La Machine Company` 的字形自带，不是独立图形对象。** 因此中文回退到别的字体后白块整体消失（见 `预览2.jpg` 的「凌 浩」）——这是模板缺陷，脚本修不了。

**大小写无差别（已验证）。** `CASPER` 与 `casper` 的墨迹尺寸完全相同（218.12 × 69.86 pt），
`CALEB`/`caleb` 亦然——该字体是全大写设计。母版用小写，沿用即可，但写大写不会丢白板。

## 模板缺陷（脚本无法修复，需设计师处理）

1. 中文名无白色印章板，且墨迹内缩 3.5–4.3mm，是拉丁名的 1.5 倍
2. `ACTOR_03/PHTOTO` 组名拼写错误，所有版本均有
3. 字号随名字长度手工变动，规则未明文
4. `PHOTO` 内部结构在版本间漂移：0805 是嵌入 RasterItem + 多一层矩形剪切；0819 是链接 PlacedItem + 单层剪切
5. `0805/killer90mins_v3.ai` 的 ACTOR_03 含一个宽度为 0 的空文字对象，坐标位于画板外，轮廓化返回垃圾值

## 逐格 R0（黑板上沿 → 名牌墨迹顶，垂线 mm）

| slot | ACTOR_01 | ACTOR_02 | ACTOR_03 | ACTOR_04 | ACTOR_05 |
|---|---|---|---|---|---|
| **目标** | 16.13 | 14.95 | 14.15 | 12.71 | 不动 |
| 认可稿 v3 | 15.28 | 14.82 | 14.35 | 12.54 | 10.99 |
| 0829（设计师说更好） | 16.98 | 15.08 | 13.95 | 12.88 | 7.90 |

目标值 = 两份认可文件的均值。机器可读版本在 `config/slots.json` 的 `slots.*.gap_panel_to_card_mm`。

**神秘嘉宾名牌单独对待**：两行内容、字号 45.61、且**完全未旋转**（与该格上沿差 8.07°），
R0 实测 7.90mm，远小于其余各格。脚本不动它。

## 前置失败条件（发现即停，不要自行造版式）

- 缺少任一动态图层或对象
- NAME 或日期被轮廓化 / 变成栅格
- 剪切路径无法安全隔离
- 演员链接缺失
- 请求的第五格模式在母版里没有对应的组
- 缺字体且替换会改变动态排版
